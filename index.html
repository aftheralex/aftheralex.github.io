Domain Outreach Assistant

Domain Outreach Assistant is a private email assistant operated by Aleksandr Isaev, an independent domain broker. It uses the Gmail API to send business emails about domain name acquisitions from the operator's own Gmail account, to read the replies in those conversations, and to label them.

It is not offered to the public and does not access anyone else's Google account.
